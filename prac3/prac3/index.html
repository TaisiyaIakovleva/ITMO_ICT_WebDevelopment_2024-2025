    Текст задания 2

    По созданным в пр.1 данным написать следующие запросы на фильтрацию:

    • Выведете все машины марки “Volvo”

    • Найти всех водителей с именем “Egor”

    • Взяв любого случайного владельца получить его id, и по этому id получить экземпляр удостоверения в виде объекта модели (можно в 2 запроса)

    • Вывести всех владельцев Серебрянных машин

    • Найти всех владельцев, чей год владения машиной начинается с 2022

    Запросы

    Все машины марки “Volvo” 

    Car.objects.filter(brand="Volvo")
<QuerySet [<Car: Volvo XC90>, <Car: Volvo S60>]>

    Все водители с именем “Egor”

    >>> Car_owner.objects.filter(firstName="Egor")
<QuerySet [<Car_owner: Danilov Egor>]>

    Взяв любого случайного владельца получить его id, и по этому id получить экземпляр удостоверения в виде объекта модели (можно в 2 запроса)

    >>> import random
>>> random_owner_id = random.choice(Car_owners.objects.all()).id
>>> Driving_licence.objects.get(owner=random_owner_id)
<License: 333 (B) - Ivanova Arina>
>>>

    Владельцы серебрянных машин

    >>>Car_owner.objects.filter(ownership_color="Silver").distinct()
<QuerySet [<Car_owner: Iakovleva Taisiia>, <Car_owner: Voronin Maksim>, <Car_owner: Ivanov Ivan>, <Car_owner: Posov Anton>]>

    Владельцы, чей год владения машиной начинается с 2022

    >>>Car_owner.objects.filter(ownership_date_start=2022).distinct()
<QuerySet [<Car_owner: Iakovleva Taisiia>, <Car_owner: Ivanova Arina>, <Car_owner: Voronin Maksim>, <Car_owner: Danilov Egor>]>

    Текст задания 3

    Необходимо реализовать следующие запросы c применением описанных методов:

    • Вывод даты выдачи самого старшего водительского удостоверения

    • Укажите самую позднюю дату владения машиной, имеющую какую-то из существующих моделей в вашей базе

    • Выведите количество машин для каждого водителя

    • Подсчитайте количество машин каждой марки

    • Отсортируйте всех автовладельцев по дате выдачи удостоверения (Примечание: чтобы не выводить несколько раз одни и те же записи воспользуйтесь методом .distinct())

    Запросы

    Дата выдачи самого старшего водительского удостоверения

    >>> from django.db.models import Min
>>> Driving_licence.objects.aggregate(Min('date_of_issue'))
{'date_of_issue_min': datetime.date(1998, 3, 3)}

    Самая поздняя дата владения машиной

    >>> Ownership.objects.aggregate(Max('date_end'))
{'date_end_max': datetime.date(2023, 7, 14)}

    Количество машин для каждого водителя

    >>> Car_owner.objects.values('firstName', 'lastName').annotate(Count('ownership_car'))
<QuerySet [{'firstName': 'Taisiia', 'lastName': 'Iakovleva', 'ownership_car_count': 2}, {'firstName': 'Ivan', 'lastName': 'Ivanov', 'ownership_car_count': 1}, {'firstName': 'Arina', 'lastName': 'Ivanova', 'ownership_car_count': 2}, {'firstName': 'Maksim', 'lastName': 'Voronin', 'ownership_car_count': 2}, {'firstName': 'Egor', 'lastName': 'Danilov', 'ownership_car_count': 2}, {'firstName': 'Anton', 'lastName': 'Posov', 'ownership_car_count': 1}]>

    Количество машин каждой марки

    >>> Car.objects.values('brand').annotate(Count('id'))
<QuerySet [{'brand': 'Mercedes-Benz', 'id_count': 1}, {'brand': 'BMW', 'id_count': 1}, {'brand': 'Volvo', 'id_count': 2}, {'brand': 'Porsche', 'id_count': 1}]>

    Автовладельцы по дате выдачи удостоверения

    >>>Car_owner.objects.distinct().order_by('date_of_issue')
<QuerySet [<Car_owner: Voronin Maksim>, <Car_owner: Ivanov Ivan>, <Car_owner: Posov Anton>, <Car_owner: Ivanova Arina>, <Car_owner: Iakovleva Taisiia>, <Car_owner: Danilov Egor>]>
